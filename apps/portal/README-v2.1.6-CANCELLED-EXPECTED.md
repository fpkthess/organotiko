# PROTOPORIA PORTAL v2.1.6 — Διαγραφή ακυρωμένων Αναμενόμενων

Στα **Οικονομικά → Αναμενόμενα**, το κουμπί «Ακύρωση» εμφανίζει προειδοποίηση.
Μετά την επιβεβαίωση η εκκρεμής πρόβλεψη **διαγράφεται** από τη βάση και παύει να εμφανίζεται στη λίστα.
Η αλλαγή ισχύει τόσο για αναμενόμενα έσοδα όσο και για αναμενόμενα έξοδα.

- Διαγράφονται **μόνο εκκρεμή Αναμενόμενα** που δεν έχουν πραγματική πληρωμή.
- Οι πραγματοποιημένες προβλέψεις και οι πραγματικές κινήσεις παραμένουν ανέπαφες.
- Κάθε ακύρωση αφήνει πλήρες snapshot στο περιορισμένο οικονομικό audit.
- Το frontend δεν προβάλλει ακυρωμένες εγγραφές ακόμη κι αν συναντήσει δεδομένα από παλιό client.
- Στην παραγωγή **ORGANOSI** η απαραίτητη migration εφαρμόστηκε ήδη και η παλιά ακυρωμένη εγγραφή αφαιρέθηκε.
- Δεν υπάρχουν αλλαγές στο Cloudflare Worker, στα SMS, στις εκδηλώσεις ή στο οικονομικό ledger.

## Εγκατάσταση

1. Αποσυμπίεσε το FULL ZIP και άνοιξε PowerShell μέσα στον φάκελο `PROTOPORIA-PORTAL-v2.1.6`.
2. Εκτέλεσε `powershell.exe -NoProfile -ExecutionPolicy Bypass -File ".\RUN-02-DEPLOY-CLOUDFLARE.ps1"`.
3. Το script σταματά σε αποτυχία build/tests και ελέγχει URL/key παραγωγής πριν το deploy.
4. Αφού επιβεβαιώσεις τον σωστό λογαριασμό Cloudflare, γράψε `DEPLOY PORTAL`.
5. Άνοιξε «Οικονομικά → Αναμενόμενα» και δοκίμασε την ακύρωση μίας μη αναγκαίας εκκρεμούς πρόβλεψης.

**Δεν εκτελείς SQL:** το `supabase/021_cancel_expected_removes_record.sql` περιλαμβάνεται μόνο για τεκμηρίωση/αναπαραγωγή σε νέα βάση. Μην επανεκτελέσεις παλιές migrations ή την εισαγωγή ιστορικού.

**Δοκιμές:** 125 αυτοματοποιημένα tests, έλεγχος συντακτικού TSX. Το πλήρες TypeScript/Vite build απαιτεί `npm install` στο Windows περιβάλλον και ελέγχεται από το script πριν την ανάπτυξη.
