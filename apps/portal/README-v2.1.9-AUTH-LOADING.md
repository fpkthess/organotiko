# PROTOPORIA PORTAL v2.1.9 — Login & Refresh Loading Fix

## Διόρθωση

Όταν το Supabase Auth ολοκληρώνει την ταυτοποίηση πριν φτάσει η απάντηση του πίνακα `profiles`, το Portal δεν εμφανίζει πλέον λανθασμένα «Δεν βρέθηκε προφίλ».

- Διακριτικό «Φόρτωση Portal…» όσο φορτώνει το προφίλ και τα αρχικά δεδομένα.
- «Δεν βρέθηκε προφίλ» **μόνο** μετά από επιβεβαιωμένη κενή απάντηση της βάσης.
- Διακριτό μήνυμα και «Επανάληψη» για σφάλμα δικτύου.
- Αγνόηση παλιών απαντήσεων όταν αλλάζει συνεδρία ή γίνονται διαδοχικά refresh.
- Όταν ανανεώνεις τα δεδομένα χειροκίνητα ενώ είσαι ήδη συνδεδεμένος, το dashboard δεν εξαφανίζεται.
- Καθαρισμός cached στοιχείων χρήστη μετά από αποσύνδεση.

Δεν υπάρχει αλλαγή στη Supabase, στα οικονομικά, στους χρήστες ή στο SMS Worker.

## Εγκατάσταση

Χρησιμοποίησε την FULL έκδοση ή το PATCH επάνω στην **v2.1.8**. Από τον φάκελο του Portal στα Windows τρέξε:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File ".\RUN-02-DEPLOY-CLOUDFLARE.ps1"
```

Το script επιβάλλει επιτυχημένο `npm run build` και `npm test` πριν από το deploy. Δεν χρειάζεται SQL migration.
