# PROTOPORIA PORTAL v2.1.8 — Mobile Compact Icons

Επιλεγμένη διόρθωση πάνω στη v2.1.7. **Μόνο η διάταξη των τεσσάρων ενεργειών στα Έσοδα / Έξοδα αλλάζει σε κινητά (≤600 px).**

- Αντί των τεράστιων 2×2 κουμπιών: **μία μικρή οριζόντια σειρά με +, μολύβι, κόκκινο καλάθι και βελάκι κάτω/πάνω**.
- Το όνομα, η ημερομηνία/κατηγορία και το ποσό μένουν ευανάγνωστα πάνω από τα εικονίδια.
- Τα κουμπιά διατηρούν περιγραφικά `aria-label`, τίτλους για βοηθητικές τεχνολογίες και την ίδια λειτουργία.
- Οι υπόλοιπες mobile αλλαγές της v2.1.7, οι desktop οθόνες, το Supabase, οι χρήστες και τα SMS **δεν επηρεάζονται**.

## Ανάπτυξη

Αποσυμπίεσε το FULL ZIP στον υπολογιστή σου. Εκτέλεσε στον φάκελο του project:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File ".\RUN-02-DEPLOY-CLOUDFLARE.ps1"
```

Το script επιβεβαιώνει τη βάση παραγωγής, εγκαθιστά npm dependencies, κάνει build και tests, και ζητά επιβεβαίωση προτού κάνει deploy. Μην τρέξεις SQL migrations. Μετά το deploy κάνε ανανέωση στο Safari.
