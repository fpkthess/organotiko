# Acceptance tests πριν από πραγματικές μαζικές SMS αποστολές

## Cloudflare / Supabase
- [ ] Frontend `npm.cmd run build` ολοκληρώνεται χωρίς TS errors.
- [ ] `npm.cmd test`: όλα τα backend unit tests περνούν.
- [ ] Migration 006 εφαρμόστηκε πρώτα σε staging + δοκιμάστηκαν όλες οι RPCs και RLS.
- [ ] Έγινε εφεδρικό αντίγραφο των δεδομένων και υπάρχει σχέδιο rollback.
- [ ] `SUPABASE_SERVICE_ROLE_KEY` εμφανίζεται μόνο στο Worker secret και ποτέ στο built JS.
- [ ] Τα secret credentials Apifon/MicroSMS είναι ρυθμισμένα στο Cloudflare.
- [ ] Το cron εμφανίζεται στα triggers του Worker και λειτουργεί με αναμενόμενο όριο subrequests.

## Χρήστες & δικαιώματα
- [ ] Admin έχει SMS menu και Sender IDs.
- [ ] Στέλεχος χωρίς `sms_access` δεν βλέπει SMS και λαμβάνει HTTP 403 με χειροκίνητο API POST.
- [ ] Χρήστης με `sms_access` αλλά χωρίς manage permissions δεν μπορεί να εισαγάγει επαφές/αλλάξει sender ή εξαιρέσεις.
- [ ] Ανενεργός χρήστης δεν μπορεί να καλέσει API παρά το έγκυρο παλιό session.
- [ ] Audit Log καταγράφει αλλαγή ρόλου, grant/revoke, import, sender και εξαίρεση με σωστό actor.

## Επαφές / εξαίρεση
- [ ] `.xlsx` με ελληνικές επικεφαλίδες αναγνωρίζεται.
- [ ] `.csv` με ελληνικές επικεφαλίδες αναγνωρίζεται.
- [ ] Μη έγκυρος αριθμός ακυρώνει **ολόκληρη** εισαγωγή και δεν σβήνει την παλιά λίστα.
- [ ] Διπλότυπα αφαιρούνται, normalizing 99/00357/+357 και 69/0030/+30.
- [ ] APPEND, REPLACE, μεμονωμένη προσθήκη και διαγραφή.
- [ ] Σχέδιο ανάκλησης consent/εξαίρεσης τηρείται.
- [ ] Import 1.500 γραμμών δεν κόβεται σε 1.000 λόγω Supabase row limit.

## Καμπάνιες / πραγματικοί πάροχοι
- [ ] Προεπισκόπηση έχει σταθερό fingerprint και απαγορεύει αλλαγμένη λίστα.
- [ ] Διπλό POST με ίδιο requestId δεν δημιουργεί δεύτερη καμπάνια.
- [ ] Αλλαγή/απενεργοποίηση Sender ID πριν το Cron αναστέλλει χωρίς πραγματική αποστολή.
- [ ] Νέα εξαίρεση πριν το Cron εξαιρεί τον αριθμό.
- [ ] Σκόπιμη διακοπή παρόχου καταγράφει UNCERTAIN χωρίς αυτόματη επαναποστολή.
- [ ] Χειροκίνητη ακύρωση σημαίνει μόνο μη αποσταλμένα SMS.
- [ ] Apifon ένα ελεγχόμενο SMS σε δικό σου αριθμό, όχι σε πραγματική λίστα.
- [ ] MicroSMS ένα ελεγχόμενο SMS σε δικό σου αριθμό, όχι σε πραγματική λίστα.
- [ ] Ιστορικό / πλήρης εξαγωγή CSV με όλες τις καταστάσεις.
- [ ] Τα παλιά GAS time triggers/εκκρεμείς καμπάνιες έχουν αντιμετωπιστεί ώστε να μην υπάρξουν διπλές αποστολές.
