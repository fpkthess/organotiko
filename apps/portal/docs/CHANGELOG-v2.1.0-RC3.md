# PROTOPORIA PORTAL — v2.1.0 RC3 (UX + Expected Estimates)

## Τι αλλάζει
- Οικονομική Διαχείριση πάνω από τις Ομάδες στο πλαϊνό μενού.
- Τύποι εκδηλώσεων σε ενιαία συμπαγή λίστα, inline μετονομασία/χρώμα, βελάκια κατάταξης και εντός εφαρμογής επιβεβαίωση διαγραφής. Η βάση διατηρεί αριθμητικό `sort_order` μόνο εσωτερικά.
- Συμπαγής κάρτα «Γενικό διαθέσιμο» και καθαρός τίτλος Οικονομικών.
- Αναμενόμενα έσοδα/έξοδα χωρίς υποχρεωτικό ποσό ή ημερομηνία. Εμφανίζονται συνολικά, ανεξάρτητα από μήνα, και τα άγνωστα ποσά δεν προστίθενται στα αθροίσματα.
- Στην πραγματοποίηση καταχωρίζεται το **πραγματικό ποσό**, που συμπληρώνεται υποχρεωτικά τότε και δημιουργεί ατομικά μία οικονομική κίνηση.
- Απλούστερο κείμενο Εσωτερικών Μεταφορών.
- Οικονομικές κατηγορίες χωρισμένες σε Έσοδα/Έξοδα, inline επεξεργασία και διακόπτες αντί browser prompt.

## Προϋποθέσεις / εγκατάσταση
1. **Μόνο στο δοκιμαστικό ORGANOSI-STAGING**: εφαρμογή της `supabase/013_expected_nullable_kind_reorder.sql` πάνω σε εγκατεστημένη 012. **Πριν από το νέο frontend.** Η αλλαγή είναι additive (χωρίς απώλεια παλαιών δεδομένων) αλλά πρέπει να δοκιμαστεί στο staging.
2. Για τοπική δοκιμή κράτησε `.env.staging` δίπλα στο package.json, χρησιμοποίησε `npm.cmd install`, `npm.cmd run build`, `npm.cmd test`, `npm.cmd run dev -- --mode staging`.
3. Μη χρησιμοποιήσεις `npm.cmd run deploy` ούτε `wrangler deploy` πριν από τελικές δοκιμές στο staging.
4. Η παραγωγή v2.0.9 παραμένει **ανέπαφη**.

## Έλεγχοι μετά την εγκατάσταση
- Δημιούργησε αναμενόμενο έσοδο χωρίς ποσό και ημερομηνία. Πρέπει να γράφει «Άγνωστο» και «Απροσδιόριστο».
- Έλεγξε ότι η αναμενόμενη εγγραφή εμφανίζεται με οποιονδήποτε επιλεγμένο μήνα και ότι το γενικό υπόλοιπο δεν αλλάζει.
- Συμπλήρωσε και επεξεργάσου ποσό αργότερα. Στην πραγματοποίηση δώσε πραγματικό ποσό, διαφορετικό από την αρχική εκτίμηση, και βεβαιώσου ότι δημιουργείται **μία** συναλλαγή.
- Δοκίμασε βελάκια αλλαγής σειράς τύπων εκδηλώσεων, αλλαγή ονομασίας και χρώματος, απενεργοποίηση και διαγραφή μόνο αχρησιμοποίητου τύπου.
- Δοκίμασε εμφάνιση mobile/desktop και αλλαγή κατηγορίας Οικονομικών.

**Ακόμη απαιτείται end-to-end έλεγχος με πραγματική συνεδρία δοκιμαστικού χρήστη.**
