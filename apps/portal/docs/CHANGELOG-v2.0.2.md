# Αλλαγές v2.0.2

- SMS: αφαιρέθηκαν οι δύο περιττές επεξηγήσεις στην Επισκόπηση και το υπότιτλο της ενότητας.
- SMS: νέα ζωντανή προεπισκόπηση SMS δίπλα στη σύνθεση· αντανακλά άμεσα Sender ID, μήνυμα και ενδεικτικό αριθμό SMS.
- SMS: πλήρης προεπισκόπηση ΟΛΩΝ των γραμμών αρχείου πριν από την εισαγωγή με πίνακα κύλισης, όχι μόνο πρώτων 5.
- SMS: επαφές ταξινομημένες ανά ελληνικό επίθετο και έπειτα όνομα. Η ταξινόμηση επηρεάζει και τη σελιδοποίηση.
- SMS: μαζική διαγραφή **μόνο** Embedded list με επιβεβαίωση, ελεγχόμενη server-side RPC και εγγραφή Audit (αριθμός εγγραφών, όχι πλήρη τηλέφωνα).
- Λογαριασμοί: Admin κουμπί «Οριστική διαγραφή», έλεγχος τελευταίου Admin και εξαρτήσεων πριν από χρήση Supabase Auth Admin API. Κανονικά αδύνατη η αυτοδιαγραφή.
- Πρόγραμμα: μόνο Admin/Ηγεσία δημιουργούν και επιβεβαιώνουν εκδηλώσεις, με server-side περιορισμό.
- Εργασίες: Συντονιστής αναθέτει στις ομάδες ευθύνης του, Στέλεχος μπορεί να δημιουργεί προσωπικές εργασίες.
- Πλοήγηση: «Όλες οι εργασίες» και «Ομάδες» κρύβονται από Συντονιστή και Στέλεχος.
- Δημιουργία Στελέχους: χωρίς παράδειγμα/placeholder ονόματος.
- Περιλαμβάνεται πλήρης πίνακας δικαιωμάτων και 29 αυτοματοποιημένες δοκιμές Worker.

## Κατάσταση παραγωγής

Στη ζωντανή βάση `ORGANOSI` εφαρμόστηκαν οι νέες RPC και οι περιορισμοί δικαιωμάτων. Η ζωντανή εφαρμογή Cloudflare **δεν έχει αναβαθμιστεί** ακόμη: χρειάζεται επιτυχές `npm.cmd run build` και `npm.cmd test` στο Windows PC, ακολούθως `npx.cmd wrangler deploy`. Η εντολή οριστικής εκκαθάρισης χρηστών, Audit Log, εργασιών, εκδηλώσεων και παλιού snapshot **δεν εκτελέστηκε**, επειδή μπλοκαρίστηκε από έλεγχο ασφάλειας του συνδεδεμένου εργαλείου. Οι 2 ήδη ολοκληρωμένες καμπάνιες SMS παρέμειναν ανέπαφες.
