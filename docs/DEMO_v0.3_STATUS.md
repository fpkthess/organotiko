# ORGANOTIKO v0.3 — Κατάσταση υλοποίησης

**Είδος παράδοσης:** Τοπική, αυτοτελής επίδειξη UI, με 260 αποκλειστικά συνθετικές εγγραφές. **Όχι παραγωγικό σύστημα**. Τα δεδομένα και οι αλλαγές υπάρχουν μόνο στο localStorage του browser της δοκιμής.

## Σημαντικά όρια

- [ ] Χωρίς πραγματική Supabase/Netlify/Auth, MFA, RLS, server-side backup, multi-user concurrency, production import ή πραγματική αποστολή SMS.
- [ ] Δεν έχει δοθεί/επιθεωρηθεί ο κώδικας του ξεχωριστού Netlify dashboard Μελών/Bluepass: η πραγματική ενοποίηση/αυτοματοποιημένη αντιστοίχιση δεν λειτουργεί. Στα Analytics Μελών/Bluepass υπάρχουν **μόνο συνθετικές ενδείξεις** από τα checkbox των εικονικών φοιτητών.
- [ ] Η ειδική διαχείριση ημέρας εκλογών από Google Sheets και τα τελικά δικαιώματα MASTER παραμένουν για επόμενη φάση.
- [ ] Οι αναφορές ΝΟΥΜΕΡΑ έχουν **πρώτο λειτουργικό ισοδύναμο** πινάκων, όχι ακόμη την πλήρη τελική λογική 4 περιόδων × 7 πραγματικών ημερών, όλες τις επιθυμητές συγκρίσεις, εξαγωγές και ακριβή πιστότητα φορμών.
- [ ] Η ταξινόμηση πυρήνων είναι δοκιμαστική (synthetic categories). Μελλοντικά χρειάζεται συσχετισμός πραγματικών προσώπων/Portal accounts, μοναδικότητα owner, πολλαπλή αρμοδιότητα και μετονομασία με ασφαλή αντικατάσταση.
- [ ] Οι ετήσιες ιστορικές αναφορές στο demo είναι τοπικά snapshots, όχι πλήρες αμετάβλητο production audit system.
- [ ] Δεν υπάρχουν πραγματικά κοινές προσωπικές/κοινές προβολές μεταξύ λογαριασμών μέχρι την ενσωμάτωση Auth.
