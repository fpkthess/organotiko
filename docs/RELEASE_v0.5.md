# Οργανωτικό v0.5 — ετήσια αναβάθμιση, Μέλη/Bluepass, πλήρης οθόνη

## Αλλαγές UI

1. **Ρυθμίσεις → Ετήσια αναβάθμιση:** πίνακας ελέγχου για *κάθε συνδυασμό πανεπιστημίου–τμήματος*, με τύπο σπουδών (προπτυχιακό/μεταπτυχιακό/ΙΕΚ), διάρκεια για προπτυχιακό και ρητή επιβεβαίωση της σχολής. Μη επιβεβαιωμένο πρόγραμμα = μπλοκαρισμένη αυτόματη πρόταση. Παρουσιάζονται όσοι χρειάζονται χειροκίνητο έλεγχο και διατηρούνται τα έτη 0/Π, ενώ η εγγραφή ΕΦΕΚΘ δεν αποχαρακτηρίζεται.
2. **Διαχείριση → Μέλη / Bluepass / Αντιστοίχιση εγγραφών:** τρεις διακριτές σελίδες. Μόνο *προεπισκόπηση προτάσεων* με όνομα/επώνυμο/τηλέφωνο από δοκιμαστικά στοιχεία. **Δεν** δημιουργείται link, δεν ενεργοποιείται flag μέλους/Bluepass, δεν γίνεται αυτόματο merge. Η πραγματική υφιστάμενη διαχείριση παραμένει σε αναμονή πηγαίου κώδικα του τρίτου συστήματος.
3. **Κεντρικός Πίνακας → Πλήρης οθόνη:** CSS full-window αντί του native Fullscreen API που απέκρυπτε App-level modal. Με το tick στο ΕΦΕΚΘ, η φόρμα πηγής/ημερομηνίας πρέπει πλέον να φαίνεται και σε πλήρη οθόνη. Ανοιχτή παραμένει και η καρτέλα φοιτητή πάνω από το μεγιστοποιημένο πλέγμα. Υπάρχει κουμπί εξόδου και υποστήριξη Escape.

## Έλεγχοι

- `node --test packages/domain/rules.test.mjs tests/*.test.mjs` — **23/23 pass** στο περιβάλλον προετοιμασίας.
- Έλεγχος συντακτικών/βασικών types με TypeScript + τοπικά QA stubs: pass με `--noImplicitAny false` (δεν υποκαθιστά build παραγωγής).
- **Δεν εκτελέστηκε πραγματικό Vite build** εδώ: DNS `EAI_AGAIN` προς npm registry.
- Ο έλεγχος fullscreen είναι στατικός στο source, όχι E2E με ενεργό auth στο Netlify. Απαιτείται πρακτική δοκιμή στο browser.

## Όρια έκδοσης

- Οι σχολικοί κανόνες αποθηκεύονται μόνο στον συγκεκριμένο browser ως πρόχειρο, **όχι** στη Supabase και δεν υπάρχει εκτελέσιμη μαζική ετήσια αναβάθμιση.
- Η πραγματική ενσωμάτωση των υφιστάμενων συστημάτων Μελών/Bluepass απαιτεί πηγαίο κώδικα, ροές έγκρισης, σχήμα και δικαιώματα. Δεν συνδέθηκε άλλη βάση.
- Οι ρυθμίσεις σχολών χρειάζονται κοινόχρηστο server-side μητρώο και εγκρίσεις πριν επιτραπεί η πραγματική αναβάθμιση.
- Δεν έγιναν νέες αλλαγές σε Supabase, Portal παραγωγής, Cloudflare, GitHub ή Netlify σε αυτή την έκδοση. Το ZIP είναι **patch**, όχι δημοσιευμένη έκδοση.
